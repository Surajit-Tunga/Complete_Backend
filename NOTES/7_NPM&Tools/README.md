# NPM & Tools

- 1. Nodejs package manager for code sharing.
- 2. **package.json:** Defines package metadata and dependencies.
- 3. to create package.json:
```bash
npm init 
```

## Installing Packages :
``` bash
npm install name
```
1. **-save** : Adds the package to the project's dependencies in package.jeson.
2. **-save-dev** : Adds the package to the project's DevDependencies in package.jeson.
3. **-g**: Install globally.
4. **-save-exact**: install the exact version specified.
5. **-force**: Force npm to install even if gives any warning.

## Installing nodemon

```bash
npm install nodemon --save-dev
```
